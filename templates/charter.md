# Charter — pinned rules

This file (your AGENTS.md / CLAUDE.md or an include it loads) is the
charter: standing rules re-loaded fresh at every session start. It is
outside every write path agent-sleep offers.

What belongs here:

- Non-negotiable working rules (verification before claiming done, candor
  about failures, confirmation before destructive actions).
- Platform credentials and access facts that must never be summarized,
  paraphrased, or carried into memory files.
- The definition of done for recurring work.

What does NOT belong here:

- Anything learned mid-session — that is memory's job, and memory is
  fallible by design (it gets verified, expired, and rebuilt).
- Rules that only apply to one project — those go in that project's own
  charter or memory, scoped.

Maintenance: charter changes are made by the human, deliberately, in a
committed edit. If an offline phase ever proposes a charter change, that
proposal is reported, never applied. Compaction drops rules in 30–59% of
episodes when they ride in context (arXiv 2606.22528) — pinning them here
is what holds that at zero.
